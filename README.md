# Т-Навигатор: Платформа ранней оценки IT компетенций и навигации в профессии 

Проект разработан в рамках образовательного интенсива Т-Образование по бизнес-аналитике. 

**Т-Навигатор** — это концепция внешней образовательной платформы для студентов 1–2 курсов IT-специальностей, направленная на раннее вовлечение, оценку навыков и помощь в построении карьерной траектории.

**[Интерактивный прототип платформы](https://aveizuu.github.io/T-Navigator/prototype/Interactive_Prototype.html)** *(откройте ссылку через GitHub Pages)*

## Проблематика

**Проблема:** Студенты 1-2 курсов часто дезориентированы, они не понимают, с чего начать путь в IT и какие навыки учить. Соответственно, они выбирают направления наугад, а Т-Образование получает большое количество нерелевантных заявок на стажировки.

## 🛠 Наше решение и проделанная работа

Мы спроектировали внешнюю платформу «Т-Навигатор». Сервис выступает единой точкой входа для студентов 1-2 курсов, помогая им пройти профтест, получить дорожную карту развития, оценить свои навыки и вовремя получать уведомления об открытии стажировок.

В рамках проекта, а именно фазы Discovery, мы провели полный цикл продуктового и системного анализа:
1. **Исследование и сбор требований:** CustDev-интервью, опрос 250 студентов, выявление Job Stories (JTBD), анализ рынка.
2. **Управление требованиями (PRD):** Написание User Stories (по критериям INVEST), критерии приемки, приоритизация функционала по методу MoSCoW.
3. **Моделирование бизнес-процессов:** Отрисовка BPMN схем AS-IS и TO-BE.
4. **Системный анализ:** Построение контекстной диаграммы системы, проектирование интеграций, разработка Role-Based Access Control.
5. **Прототипирование:** Создание интерактивного HTML прототипа платформы.
